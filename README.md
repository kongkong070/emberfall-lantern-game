Emberfall is a wave-based arena shooter: you are the keeper of the last lantern, shooting embers at shades that crawl out of the dark to snuff it out. Survive 10 waves, pick a blessing after each wave, and bring the dawn back.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Move with WASD or arrow keys, aim with the mouse, hold click (or Space) to shoot. Press 1, 2 or 3 (or click a card) to pick an upgrade between waves. P pauses, M mutes.
